# اپ وب تبدیل صوت به متن

## اجرا

برای خروجی زیرنویس، از Python 3.13 و محیط مجازی استفاده کنید:

در ویندوز، برای نصب و اجرا از فایل‌های زیر استفاده کنید. نصب‌کننده از Python 3.13 داخل پروژه استفاده می‌کند و Python پیش‌فرض سیستم را تغییر نمی‌دهد:

```powershell
.\setup_srt.bat
.\run_srt.bat
```

اگر محیط محلی از قبل آماده است، اجرای `run_srt.bat` کافی است. `setup_srt.bat` برای آماده‌سازی Python به Python install manager نیاز دارد.

روش جایگزین، در صورتی که Python 3.13 را نصب کرده‌اید:

```powershell
cd audio-to-text-web
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-srt.txt
.\run_srt.bat
```

در لینوکس و مک:

```bash
cd audio-to-text-web
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-srt.txt
.venv/bin/python app.py
```

سپس در مرورگر برو به: http://localhost:5000

اگر فقط خروجی TXT می‌خواهید، نصب `requirements.txt` و اجرای `python app.py` کافی است. TXT فرمت پیش‌فرض است و شروع برنامه به وابستگی‌های SRT نیاز ندارد.

## ویژگی‌ها
- آپلود فایل صوتی
- پشتیبانی از زبان فارسی (پیش‌فرض)
- انتخاب متن ساده TXT (پیش‌فرض) یا زیرنویس SRT
- زیرنویس جمله‌ای با زمان شروع و پایان بر اساس زمان‌بندی واژه‌ها در صوت اصلی
- تفکیک بر اساس نشانه‌های پایان جمله و مکث‌های حداقل یک ثانیه؛ شکستن جمله‌های طولانی در مرز واژه‌ها برای خوانایی
- دانلود جداگانهٔ خروجی هر فایل با نام فایل صوتی و پسوند `.srt` یا `.txt`
- دانلود خودکار و نمایش لینک خروجی هر فایل بلافاصله پس از پایان پردازش همان فایل، در حالی که پردازش فایل‌های بعدی ادامه دارد
- تغییر دکمهٔ «تبدیل به متن» به «توقف پردازش» هنگام شروع؛ امکان توقف آپلود یا تبدیل و شروع دوباره

اگر مرورگر دانلود خودکار چند فایل را محدود کرد، از لینک‌های جداگانهٔ نمایش‌داده‌شده در صفحه استفاده کنید.

با کلیک روی «توقف پردازش»، فرایند همان درخواست و ابزارهای صوتیِ وابسته به آن متوقف می‌شوند. خروجی فایل‌های تکمیل‌شده همچنان قابل دانلود است؛ خروجی ناقص حذف می‌شود. در صورت خطا در فایل بعدی نیز خروجی فایل‌های قبلی حفظ می‌شود. پس از پایان یا توقف، دکمه به «تبدیل به متن» برمی‌گردد. هر درخواست وضعیت و فرایند مستقل دارد.

## نیازمندی‌ها
- Python 3.13 برای مسیر SRT (وابستگی‌های بومی روی Python 3.15 این سیستم نصب نشدند)
- `requirements-srt.txt` برای SRT؛ شامل نیازمندی‌های TXT نیز هست
- ffmpeg و ffprobe برای مسیر TXT؛ مسیر SRT صوت را مستقیماً با faster-whisper می‌خواند

اگر ffmpeg یا ffprobe در PATH پیدا نشود، تبدیل TXT متوقف می‌شود و پیام خطا راهنمای نصب و تنظیم PATH را نشان می‌دهد. نصب خودکار از داخل برنامه انجام نمی‌شود. در ویندوز می‌توانید دستور زیر را در PowerShell اجرا کنید و سپس پنجرهٔ اجرای برنامه را ببندید و دوباره باز کنید:

```powershell
winget install --id Gyan.FFmpeg -e
```

### خطای نصب CTranslate2

اگر نصب با `No matching distribution found for ctranslate2` متوقف شد، نسخه و معماری Python مورد استفاده را بررسی کنید. در این سیستم، دستور عمومی `python` به Python 3.15 اشاره می‌کند، درحالی‌که وابستگی‌های SRT با Python 3.13 نسخهٔ ۶۴ بیتی در `.runtime/python313` نصب و آزمایش شده‌اند.

فایل `setup_srt.bat` نصب را با همان مفسر سازگار انجام می‌دهد. برای نصب دستی در همین محیط نیز از دستور صریح زیر استفاده کنید:

```powershell
.\.runtime\python313\python.exe -m pip install -r requirements-srt.txt
```

## تبدیل به SRT

در فرم «زیرنویس SRT» را انتخاب کنید. هر فایل خروجی مستقل دارد و شماره‌گذاری زیرنویس آن از ۱ شروع می‌شود:

```srt
1
00:00:01,200 --> 00:00:03,400
سلام، این جملهٔ اول است.

2
00:00:04,100 --> 00:00:06,800
این هم جملهٔ دوم است.
```

تبدیل با مدل چندزبانهٔ `small` از Whisper روی CPU انجام می‌شود و کلید API نمی‌خواهد. در اولین اجرا، مدل از اینترنت دانلود می‌شود؛ اجراهای بعد از نسخهٔ ذخیره‌شده استفاده می‌کنند. فایل `run_srt.bat` مدل‌ها را در پوشهٔ `models` پروژه نگه می‌دارد. این فایل ابتدا محیط محلی `.runtime/python313` و سپس `.venv` را بررسی می‌کند.

برای تغییر مدل یا استفاده از مدل دانلودشده، متغیر محیطی `WHISPER_MODEL` را به نام مدل یا مسیر محلی آن تنظیم کنید. مسیر ذخیرهٔ مدل با `WHISPER_DOWNLOAD_ROOT` قابل تنظیم است.

زمان‌ها از زمان‌بندی واژه‌های مدل گرفته می‌شوند؛ تقسیم مساوی زمان بین جمله‌ها انجام نمی‌شود. تفکیک جمله و زمان‌بندی خودکار است و ممکن است در صوت کم‌کیفیت نیاز به بازبینی داشته باشد.
